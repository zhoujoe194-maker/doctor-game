## 已通过

- 11 项算法测试：颜色候选、越过/不足轨迹、采样拒绝、多目标拒绝、未确认/排除/合成数据不触发调整、调整方向与幅度、习惯差异、输入校验、已知背景位移、预瞄与未知场景不触发调整。
- 3 项浏览器端到端测试：玩家档案持久化、回放确认/排除/恢复、响应式布局与无障碍扫描；真实 MediaRecorder 编码 + IndexedDB 分块保存 + seek 解码 + 报告持久化；录屏被拒绝后的重试路径。
- 桌面冒烟测试：隔离用户目录中的本地 IPC、合成录像落盘、自定义媒体协议的 Range 读取、视频解码与图像读取、赛后报告；渲染器没有 Node.js `require`；200% 缩放无横向溢出。
- 工作台、玩家档案、报告页面通过 axe 自动扫描；工作台在 1440、768、390、320 px 宽度检查，档案页面在窄屏检查溢出。已检查键盘焦点和 reduced-motion 配置。
- 实际渲染截图已查看，修正了窄屏导航缺失名称、重复区域名称、本地录像跨源画布读取、移动端空状态拥挤等问题。

测试均使用程序生成的视频与合成数据，未启动用户的游戏录屏，也未分析私人录像。

## 没有验证的事项

- Windows 实机 VALORANT 窗口捕获、全屏模式、Vanguard 兼容性、后台长时间录制、CPU/GPU 占用和帧率影响。
- 真实对局中的敌人识别准确率、轨迹误差、场景检测准确率；没有训练或评估自动击杀/死亡识别模型。
- 预瞄背景运动是否能有效分离角色移动、后坐力和视角转动；未将它表述为手部平滑度。
- 调整灵敏度后能否提高真实表现。规则阈值和玩家习惯的数值映射尚无实验依据。
- 屏幕阅读器人工验收、Core Web Vitals 和全部 WCAG 条款。自动扫描通过不等于 WCAG 合规认证。
- 长对局的处理时间与存储压力。当前逐帧 seek 方案可取消，但还没有高吞吐解码流水线。

截图位于 `artifacts/`，由端到端测试生成。Windows 包即使生成成功，也只说明跨平台打包完成，不代表上述 Windows 运行验证已经通过。
