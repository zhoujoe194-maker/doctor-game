# Windows 测试版界面设计

基线：`4d72b91`。本次按 `game-ui-ux` 与项目版 `frontend-design` 执行。

## 参考与取舍

已打开仓库原有工作台、报告截图，并在本机 Chromium 中查看了任务文档链接的
[Aimlabs 官方结果页图片](https://clan.fastly.steamstatic.com/images/30632227/061487196be8880f4f28cd7e0ed1cdc7e217b15c.png)。
该图把回放、时间线和后续操作组织在相邻区域。doctorgame 采用这一操作顺序，
保留自己的图标、中文、深绿导航和浅绿操作色，不复制排行榜、成绩评分或品牌素材。

旧版问题：空工作台中央的静态准星不提供操作；片段列表位于视频和长篇说明之下；
每次确认都会重建播放器并丢失播放位置。新版优先减少点击和上下滚动。

## 视觉与布局

- 配色：森林绿 `#192a23`、浅绿 `#c2f279`、画布 `#f5f6f2`、白色 `#ffffff`、
  正文 `#1d2b22`、辅助文字 `#58665b`。录像保持原色、不裁切。
- 字体：本机中文黑体（苹方 / 微软雅黑）；标题有层次但不作宣传语。
  时间和数值用等宽数字，关键操作保持清晰焦点环与至少 44 px 点击区域。
- 首页：左对齐的录制/导入操作区；紧凑档案栏；最近一局直接进入复盘。
- 复盘：大视频与右侧片段列表并排；片段时间线、速度和确认控件紧邻视频。
  小窗口变为单列，片段列表可折叠。详细轨迹与实验依据按需展开。

```text
首页                           赛后复盘
导航 | 录制与复盘              导航 | 标题、样本数、当前建议
     | 开始录制  导入录像           | 视频              | 片段筛选
     | DPI / 灵敏度 / 编辑         | 时间线            | 片段列表
     | 最近一局 → 继续复盘         | 慢放              | 确认 / 排除
     | 更多记录                    | 展开：轨迹与复测说明
```

设计复核：去掉装饰编号、口号和重复统计卡；浅绿只强调当前操作与选中片段。
没有评分、击杀准确率、握姿推导出的数值等未经验证的内容。

## 交互验收

片段点击跳到片段起点；“回放前后过程”另行包含上下文。确认、排除、恢复和筛选
不重建视频，也不丢失速度或当前位置。状态包含文字，样本数遵守原推荐资格，
演示始终计为零个真实量化样本。窗口选择取消后焦点返回录制按钮。

验收尺寸包括 1440×900、1280×720、760×620，并保留浏览器窄屏检查。
用实际 Tab / Enter / Escape 测试主要操作、弹窗和焦点返回。
