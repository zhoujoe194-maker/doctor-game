# doctorgame Windows 原型

将整个文件夹放在 Windows 电脑上，双击 `doctorgame.exe`。请保留同目录的所有文件。

1. 在「玩家档案」填写实际 DPI、游戏灵敏度、高亮颜色、瞄准方式和握姿。
2. 启动无畏契约，点击「开始观察」，选择游戏窗口。
3. 游戏结束后点击「结束并分析」。录制时关闭窗口会留在托盘，可从托盘打开或停止。
4. 先回放并确认候选片段；可以慢放、查看前后过程，手动补充漏掉的关键事件。
5. 样本不足时保持当前值。建议数值是待验证的小幅试用值，不是已证实的最佳灵敏度。

这是未签名的开发原型，尚未完成 Windows 实机游戏捕获、Vanguard 兼容性和真实录像准确率验证。遇到系统拦截时无需关闭系统保护，可先使用源码和浏览器预览检查功能。

录像仅保存在本机，不录制麦克风。点击「对局记录 → 打开录像文件夹」可管理录像；报告与档案保存在应用本地存储。

场景定位目前结合自动颜色/视角运动候选与人工确认；尚未自动识别击杀或死亡语义。玩家手动标记的片段只用于复盘，不被当成量化瞄准样本。
